
PYTHON WEEK 8 - TOOLKIT PLAN

1. TOOLS

Tool 1: Simple Calculator
This tool allows users to add, subtract, multiply and divide two numbers.
Concepts: Input, conditionals, arithmetic and f-strings.

Tool 2: To-Do List
This tool allows users to add, view and remove tasks.
Concepts: Lists, loops, append(), pop() and conditionals.

Tool 3: Number Guessing Game
This tool allows users to guess a secret number and receive hints.
Concepts: While loops, conditionals and f-strings.
