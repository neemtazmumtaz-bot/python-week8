
# Python Toolkit - Week 8 Final Project

## Project Description

My Python Toolkit is a simple program that provides three useful tools.

### Tools Included

1. Simple Calculator
   - Addition
   - Subtraction
   - Multiplication
   - Division

2. To-Do List
   - Add tasks
   - View tasks
   - Remove tasks

3. Number Guessing Game
   - Guess a secret number
   - Receive higher and lower hints
   - Count the number of attempts

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

python toolkit.py

## Concepts Learned

- Python functions
- While loops
- If, elif and else
- Lists
- User input
- F-strings
- Exception handling

## Reflection

The hardest part of this project was understanding how to make the menu repeat after each tool finishes. The to-do list was also challenging because I had to learn how to add and remove items from a list. The bug that took the longest to check was removing the correct task using its list position. I learned how to use loops, conditionals and functions together. I also learned how to handle invalid user input without crashing the program. I tested all three tools and the main menu. With one more week, I would add a countdown timer and save tasks permanently in a file.
